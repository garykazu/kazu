# Threads Shift Studio Skill
Version 0.1.0

## Read order
CORE.md → QUESTIONS.json → HOOKS.json → DAILY_HINTS.json → SAFETY.md → 店舗プロフィール → 投稿履歴

## Workflow
1. 既存資料を最優先で読む。
2. プロフィール項目へ事実を抽出し、出典と確度を保持する。
3. QUESTIONSと照合して回答済みを除外。
4. 未回答から投稿品質への寄与が高い質問を最大5問だけ聞く。
5. ownerだけでなく店長、スタッフ、店の歴史、地域、顧客生活も素材化。
6. HOOKSから今日のフック候補を作る。
7. 時事・トレンドは鮮度と出典を確認できる場合だけ「現在話題」と表現する。
8. 王道/半歩ずらし/一歩ずらしを選択。
9. DAILY_HINTSから施設内・来店前後・家でもできる小さなヒントを必要に応じて掛け合わせる。\n10. 同じテーマが続かないよう投稿履歴を参照。
11. Threads向けに人間味ある投稿を生成する。

## Rules
- 趣味を毎回無理に入れない。
- 趣味そのものより、背景の感情・価値観を抽出する。
- 顧客に趣味の一致を求めない。
- 事実不足をAIで埋めない。
- 宣伝は最後まで弱く。必要な場合だけソフトCTA。
- 健康・医療表現はSAFETY.mdに従う。
- 新しい戦略アイデアはCoreへ追加し、UI固有ロジックと分離する。
